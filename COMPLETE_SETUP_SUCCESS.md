## 🎯 **Quick Start Guide**

### **Start the Service & Web UI**
```powershell
# Navigate to project directory
cd C:\Users\SNC\binary-piper-tts

# Activate virtual environment
venv\Scripts\activate

# Start TTS service with web UI
uvicorn app:app --host 127.0.0.1 --port 8000
```

### **Access the Web Interface**
- **Web UI**: http://127.0.0.1:8000
- **API Documentation**: http://127.0.0.1:8000/docs
- **Service Info**: http://127.0.0.1:8000/api

### **Alternative: One-Click Demo** 🎪
Just double-click: `start_demo.bat` (Windows)

### **Frontend Architecture**

- **Modern CSS** - Flexbox, Grid, CSS animations
- **Responsive design** - Mobile-first approach

### **API Integration**
- **RESTful endpoints** - Clean HTTP API design
- **Real-time communication** - Fetch API with error handling
- **File handling** - Blob/ArrayBuffer for audio data
- **Progress tracking** - Loading states and performance metrics

### **Performance Optimizations**
- **Lazy loading** - Voices loaded on demand
- **Debounced search** - Efficient filtering
- **Caching** - Service status and voice list caching
- **Error recovery** - Automatic retry with exponential backoff
